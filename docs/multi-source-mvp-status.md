# 多网站视频 App：第一版实现记录

## 已提交的功能
- Android 原有搜索页新增「多站搜索 / 原搜索」切换，默认展示多站搜索
- 多站页面含「聚合搜索 / 管理网站 / 离线」三部分
- 预置用户要求的 6 个候选视频站；示例网址仅作说明，并非固定作品列表
- App 内输入新网站 HTTPS URL，保存网站、启用或禁用、删除自定义网站
- 自动尝试识别公开 HTML GET 搜索表单；可人工编辑搜索 URL 模板（必须包含 `{query}`）
- 运行时按关键词读取各网站的公开搜索页面并提取候选链接，单站失败不影响其他来源
- 尝试从公开详情 HTML 的 video/source/a/og:video 元素发现直接 MP4、WebM、m3u8
- MP4/WebM 直接视频文件的下载（仅在允许下载时使用）；显示进度，写入 App 私有目录，提供离线播放及删除
- 仅把已下载完毕的文件列为离线视频，流媒体缓存不会被标成离线文件
- GitHub Actions 构建 Android ARM64 测试 APK，修改源码会触发构建

## 与最终目标的差距
- **未完成**：逐个验证 6 个网站的搜索页结构、剧集提取、播放接口与权限。通用解析对于 JavaScript 渲染、POST 搜索、复杂页面经常无效
- **未完成**：保证任意网站输入 URL 后即可完整融合；识别不到标准 GET 搜索表单时仍需专用适配器
- **未完成**：HLS 多段下载/离线合并、剧集批量下载、暂停续传、后台下载和跨设备同步
- **未完成**：DRM、会员受保护或无权下载视频的离线保存（不绕过此类保护）
- **未完成**：GitHub Actions 实际构建成功与 Android 真机安装/播放/下载验证
- 下载存在单任务与 2GB 文件大小限制；下载路径为应用私有目录，卸载 App 可能删除文件
- 当前自动识别的搜索规则只做结构发现，不保证网站端的搜索 API 真实可用

## 代码位置
- `src/sourceHub.ts`：网站管理、搜索规则和 HTML 解析
- `src/pages/SourceHub.tsx`：多网站搜索、网站添加及离线页面
- `src/pages/Search.tsx`：界面入口
- `src-tauri/src/source_hub.rs`：安全抓取、视频下载、离线 Range 服务
- `src-tauri/src/lib.rs`：注册原生命令和离线服务
- `.github/workflows/android-apk.yml`：安卓自动构建

## 安全与权限
自定义网站仅允许公开 HTTPS 域名，原生访问使用项目已有网络防护，不关闭内网阻断。网页作为数据读取，不执行远程 JavaScript。播放或下载必须遵守版权、会员授权、网站条款，不解除 DRM 或绕过保护。
